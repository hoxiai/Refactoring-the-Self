# 傳奇私服

## —— 萬鵬、私服，和屏幕後面的那扇門

那次捱打以後，我在“輕鬆一點”裏才算真正混了個臉熟。

蝦子、狗子，還有萬鵬。

他們幾個總在。

湊錢上機，湊錢買煙，一坐就是一整晚。

那時候我還不知道萬鵬到底在幹什麼。

只知道他跟我們不太一樣。

我們來網吧，是為了打傳奇。

他也打，但更多的時候，他是在拆傳奇。

後來我才知道，網吧裏很多人玩的那個私服，就是他自己架的。

這一下就把我勾住了。

因為傳奇官服太慢了。

升級慢。

裝備也難打。

有時候熬一個通宵，經驗沒漲多少，裝備也沒打到。

可私服不一樣。

等級可以改。

裝備可以改。

爆率也可以改。

同樣一個傳奇，到了他手裏，好像什麼都能動。

我那時候什麼都不懂。

只覺得這事挺神奇。

所以我開始往萬鵬旁邊坐。

有時候買包紅河，給他遞一根。

自己也點上一根。

他在裏面忙，我就在旁邊看。

有些窗口我看不懂。

有些文件，我連名字都叫不出來。

他也不怎麼管我。

偶爾我問一句，他就説一句。

説完繼續弄他的。

後來有一次，他讓我自己進去試。

人物身上什麼裝備都沒有。

光着身子。

手裏拿着一把最普通的刀。

然後把自己的屬性直接調滿。

攻擊、血量、防禦。

能調的全調了。

我站在地圖裏，看着那個光着身子的人物，覺得有點好笑。

然後我又把網吧裏一個平時挺囂張的人召喚了過來。

他可能還沒明白怎麼回事。

我過去。

一刀。

人沒了。

那一下特別爽。

以前打怪，要一點一點砍。

打人，要看裝備。

碰到厲害的，還得跑。

可那時候不一樣。

我什麼都沒有。

一身光。

一把破刀。

但誰站到我面前，我都可以一刀把他放倒。

我又試了幾次。

還是一樣。

一刀。

人沒了。

開始的時候特別爽。

後來慢慢就沒感覺了。

我發現，已經沒什麼可玩的了。

以前升級，是為了變強。

打裝備，也是為了變強。

可現在已經到頭了。

什麼都不用了。

裝備不用。

等級不用。

時間也不用花。

站在那裏，就是最強。

我坐在電腦前，突然不知道該幹什麼了。

傳奇還是那個傳奇。

可我不想玩了。

後來我再去“輕鬆一點”，已經很少開傳奇。

但我還是會坐到萬鵬旁邊。

看他弄那些我看不懂的東西。

我開始問一些以前不會問的問題。

這個是什麼？

這個改了會怎麼樣？

這個東西為什麼能影響遊戲？

萬鵬有時候回答。

有時候懶得理我。

我也不急。

就坐在那裏看。

別人還在裏面砍怪。

我開始盯着他屏幕上的那些窗口。

那時候我還不知道，那些東西到底是什麼。
