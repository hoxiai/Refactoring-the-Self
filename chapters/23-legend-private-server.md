# 传奇私服

## —— 万鹏、私服，和屏幕后面的那扇门

那次挨打以后，我在“轻松一点”里才算真正混了个脸熟。

虾子、狗子，还有万鹏。

他们几个总在。

凑钱上机，凑钱买烟，一坐就是一整晚。

那时候我还不知道万鹏到底在干什么。

只知道他跟我们不太一样。

我们来网吧，是为了打传奇。

他也打，但更多的时候，他是在拆传奇。

后来我才知道，网吧里很多人玩的那个私服，就是他自己架的。

这一下就把我勾住了。

因为传奇官服太慢了。

升级慢。

装备也难打。

有时候熬一个通宵，经验没涨多少，装备也没打到。

可私服不一样。

等级可以改。

装备可以改。

爆率也可以改。

同样一个传奇，到了他手里，好像什么都能动。

我那时候什么都不懂。

只觉得这事挺神奇。

所以我开始往万鹏旁边坐。

有时候买包红河，给他递一根。

自己也点上一根。

他在里面忙，我就在旁边看。

有些窗口我看不懂。

有些文件，我连名字都叫不出来。

他也不怎么管我。

偶尔我问一句，他就说一句。

说完继续弄他的。

后来有一次，他让我自己进去试。

人物身上什么装备都没有。

光着身子。

手里拿着一把最普通的刀。

然后把自己的属性直接调满。

攻击、血量、防御。

能调的全调了。

我站在地图里，看着那个光着身子的人物，觉得有点好笑。

然后我又把网吧里一个平时挺嚣张的人召唤了过来。

他可能还没明白怎么回事。

我过去。

一刀。

人没了。

那一下特别爽。

以前打怪，要一点一点砍。

打人，要看装备。

碰到厉害的，还得跑。

可那时候不一样。

我什么都没有。

一身光。

一把破刀。

但谁站到我面前，我都可以一刀把他放倒。

我又试了几次。

还是一样。

一刀。

人没了。

开始的时候特别爽。

后来慢慢就没感觉了。

我发现，已经没什么可玩的了。

以前升级，是为了变强。

打装备，也是为了变强。

可现在已经到头了。

什么都不用了。

装备不用。

等级不用。

时间也不用花。

站在那里，就是最强。

我坐在电脑前，突然不知道该干什么了。

传奇还是那个传奇。

可我不想玩了。

后来我再去“轻松一点”，已经很少开传奇。

但我还是会坐到万鹏旁边。

看他弄那些我看不懂的东西。

我开始问一些以前不会问的问题。

这个是什么？

这个改了会怎么样？

这个东西为什么能影响游戏？

万鹏有时候回答。

有时候懒得理我。

我也不急。

就坐在那里看。

别人还在里面砍怪。

我开始盯着他屏幕上的那些窗口。

那时候我还不知道，那些东西到底是什么。
